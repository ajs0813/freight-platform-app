# 🚚 Freight Platform App

국내 화물운송 플랫폼의 사업 가능성을 검토한 기획 기록입니다.

소프트웨어 작업은 기획·타당성 검토 → 업무 정의 → 플랫폼 설계 → 개발·테스트 → 출시·운영 순서로 구분했습니다. 현재는 **기획·타당성 검토 후 개발을 보류**한 상태입니다.

## 검토 목적

화물 운송을 의뢰하는 고객과 운송 수행자를 연결하는 서비스가 기존 시장에서 어떤 가치를 만들 수 있는지 살펴봤습니다. 고객 확보 방법과 지속 가능한 수익 구조를 확인한 뒤 개발 여부를 판단하는 것이 목적입니다.

## 검토한 사업 모델

| 방식 | 플랫폼이 맡는 일 | 검토할 수익 |
|---|---|---|
| 화물 정보망 | 화물·차량 정보의 등록·검색 지원 | 정보이용료 |
| 사업자 연결 | 화주와 운송사·주선사가 만날 수 있도록 지원 | 과금 방식 미정 |
| 직접 주선 | 플랫폼이 운송 계약의 중개·대리와 배차에 관여 | 주선 수수료 |

직접 주선은 정보 제공보다 책임 범위가 넓으며 관련 사업 허가가 필요합니다. 실제 서비스별 수수료율은 확인하지 못했습니다. [화물자동차 운수사업법 제24조](https://www.law.go.kr/LSW/lsInfoP.do?lsId=001748)

## 시장에서 확인한 점

전국24시콜화물·원콜·화물맨은 국내 화물 **정보망**을 살펴볼 때 중요한 기존 사업자입니다. 이는 전체 운송시장의 매출 순위를 뜻하지 않습니다. 2024년 11월 안드로이드 앱 이용 자료에서는 이들 서비스의 이용 규모가 후발 앱보다 컸습니다. 차주는 여러 앱을 함께 사용할 수 있어 이용자 수를 단순 합산해 시장 고객 수로 보지 않습니다. [한국경제(2024)](https://v.daum.net/v/20241223160107223)

기존 사업자에게는 화주·주선사 영업망과 차주의 거래 관계가 쌓여 있습니다. 새 앱은 기능만 제시해서는 부족하고, 실제 일감과 기존 거래보다 나은 이유를 제공해야 합니다. [한국경제(2024)](https://v.daum.net/v/20241223160107223)
